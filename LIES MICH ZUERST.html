Me Goos-ta Deutsch – so geht der Start

Lernkarten zum Ausdrucken: vorne ein Gans-Wortspiel-Bild, hinten das Wort auf Spanisch (gemeint ist immer das in Mexiko gesprochene Spanisch).Alles läuft auf deinem Rechner – Internet braucht es nur einmal für die Einrichtung und, wenn du willst, für die automatische Übersetzung.

Neu in Version 2.3: Ideen bekommen ihr Bild leichter – ein Knopf „🖼️ Bild wählen …“ für Fotos und fertige Bilder (mit Vorschau: „GANS + Wort“ daraufsetzen oder unverändert übernehmen) · „🪄 Mit KI erzeugen …“ direkt an der Idee – das Bild landet gleich bei ihr · neues Feld „Bildidee“ – dein Merkzettel, wie das Bild aussehen könnte, zugleich die Beschreibung für die KI · Update ohne Datenverlust wie gewohnt (siehe unten).

  1. ZIP-Datei freigeben wichtig bei Windows 11

    Rechtsklick auf die heruntergeladene ZIP-Datei → „Eigenschaften“ → unten bei „Sicherheit“ ein Häkchen bei „Zulassen“ → „OK“.

    Warum? Windows markiert Dateien aus dem Internet. Die „Intelligente App-Steuerung“ (Smart App Control) blockiert markierte Startdateien. Gibt es kein Kästchen „Zulassen“, ist die Datei nicht markiert – dann einfach weiter.

  2. Entpacken

    Rechtsklick auf die ZIP-Datei → „Alle extrahieren …“ → „Extrahieren“. Tipp: als Ziel z. B. „Dokumente“ wählen – der Ordner ist dein Arbeitsordner mit Bildern und PDFs.

  3. Starten

    Im entpackten Ordner doppelklicken auf „Me Goos-ta Deutsch - Windows“ (Typ „Windows-Befehlsskript“).

    Beim ersten Start richtet sich alles selbst ein – Fenster offen lassen, etwa 3–10 Minuten, ca. 90 MB Download: eigenes Python, Pakete, Desktop-Symbol. Danach öffnet sich die Oberfläche im Browser.

    Ab dann: Doppelklick auf das Desktop-Symbol „Me Goos-ta Deutsch“ (oder im Startmenü) – startet in Sekunden, ohne schwarzes Fenster.

Schon eine ältere Version? So klappt das Update

Die neueste Version gibt es immer auf der Download-Seite: lukasdiegans.github.io/me-goos-ta-deutsch/download – ein Paket für Windows, macOS und Linux.

Deine Karten, Bilder und PDFs bleiben erhalten – die neue Version bringt davon nichts mit außer ihren Beispielkarten.

  1. Die laufende Oberfläche beenden (⏻ oben rechts).
  2. Die neue ZIP-Datei freigeben (Windows: Schritt 1) und in einen neuen Ordner entpacken – „Alle extrahieren …“ schlägt selbst einen vor, der Mac legt ohnehin einen neuen an.
  3. Im neuen Ordner die Startdatei doppelklicken. Sie findet den bisherigen Ordner und fragt, ob deine Karten übernommen werden sollen: „Ja“ bzw. im Startfenster einfach Enter. Kopiert werden Karten, Bilder, schon verbesserte Bilder, Einstellungen und ein eigenes Gänse-Bild – nichts muss neu geladen werden.
  4. Das Symbol startet ab jetzt die neue Version. Der alte Ordner bleibt unverändert und kann weg, sobald alles passt.

Auch möglich: über den alten Ordner entpacken und „Dateien im Ziel ersetzen“ wählen – ersetzt werden nur Programmdateien, nie deine Karten oder Bilder.

Was beim ersten Start passiert

  • Eigenes Python – offiziell von python.org (Windows) bzw. python-build-standalone (Mac und Linux), mit Prüfsumme kontrolliert. Es liegt im Benutzerordner, braucht keine Administratorrechte und lässt andere Python-Installationen unberührt.
    Windows: %LOCALAPPDATA%\Me-Goos-ta-Deutsch · Mac: ~/Library/Application Support/Me-Goos-ta-Deutsch · Linux: ~/.local/share/me-goos-ta-deutsch
  • Pakete Pillow, NumPy, ReportLab, pypdfium2 (von pypi.org). Größere Extras – die Tools Bildverbesserung (Real-ESRGAN), automatische Übersetzung, KI-Bilder und weitere Sprachen für die Rückseite – sind nicht vorinstalliert: Du wählst sie beim ersten Öffnen oder später unter „Werkzeuge“. Mit dem Tool „Karten lernen“ übst du deine Karten direkt im Programm wie mit Anki (Reiter „🎓 Lernen“).
  • Symbol auf dem Desktop und im Startmenü (Windows), App im Ordner „Programme“ (Mac) bzw. Eintrag im Anwendungsmenü (Linux).
  • Die Download-Markierung wird von den eigenen Dateien entfernt, damit spätere Starts nicht wieder blockiert werden.

Bei jedem weiteren Start prüft das Startprogramm in Sekunden, ob alles da ist. Läuft die Oberfläche schon, öffnet es nur den Browser. Fehlt etwas oder ist etwas beschädigt, repariert es das selbst.

Wo liegt was?

Programm/ enthält das Programm und deine Arbeit: bilder/ (deine Fotos), karten.csv (die Wörter), ausgabe/ (die fertigen PDFs). In der Oberfläche öffnet „Werkzeuge“ alle Ordner direkt. Anleitung zum Kartenmachen: Oberfläche → „Hilfe“ oder Programm/LEITFADEN.md.

Me Goos-ta Deutsch – how to start

Printable flashcards: a goose-pun picture on the front, the word in Spanish on the back (always meaning Spanish as spoken in Mexico).Everything runs on your computer – internet is only needed once for the setup and, if you like, for automatic translation.

New in version 2.3: Ideas get their image more easily – one “🖼️ Choose image …” button for photos and finished images (with a preview: add “GANS + word” or use it unchanged) · “🪄 Create with AI …” right on the idea – the image goes straight to it · new “Image idea” field – your note on what the image could look like, which is also the description for the AI · updates without losing data, as always (see below).

  1. Unblock the ZIP file important on Windows 11

    Right-click the downloaded ZIP file → “Properties” → at the bottom under “Security” tick “Unblock” → “OK”.

    Why? Windows marks files from the internet, and Smart App Control blocks marked start files. If there is no “Unblock” box, the file is not marked – just continue.

  2. Extract

    Right-click the ZIP file → “Extract All …” → “Extract”. Tip: choose e.g. “Documents” – the folder is your working folder with pictures and PDFs.

  3. Start

    In the extracted folder, double-click “Me Goos-ta Deutsch - Windows” (type “Windows Command Script”).

    On the first start everything sets itself up – keep the window open, about 3–10 minutes, about 90 MB download: its own Python, packages, desktop icon. Then the interface opens in the browser.

    From then on: double-click the desktop icon “Me Goos-ta Deutsch” (or use the Start menu) – starts in seconds, without a black window.

A warning appears?
“Windows protected your PC” → “More info” → “Run anyway”.
“Smart App Control … blocked” → step 1 was skipped: right-click “Me Goos-ta Deutsch - Windows” → “Properties” → “Unblock” → “OK”, then double-click again.

  1. Extract

    Double-click the ZIP file (Safari often extracts it by itself). Best move the folder to “Documents”.

  2. Start

    Double-click “Me Goos-ta Deutsch - Mac”.

    If macOS says the file cannot be opened (“Apple could not verify …”):

    • macOS 15 and later: close the message → System Settings → Privacy & Security → at the bottom next to “Me Goos-ta Deutsch - Mac” click “Open Anyway” → confirm.
    • macOS 14 and earlier: hold the Control key, click the file → “Open” → “Open”.
    • Always works: open the “Terminal” app, type sh and a space, drag the file into the Terminal window, press Return.

    If macOS asks for access to “Downloads” or “Documents”: “Allow”.

  3. First start and afterwards

    On the first start everything sets itself up (keep the Terminal window open, 3–10 minutes, about 90 MB). Then the interface opens in the browser.

    From then on: “Me Goos-ta Deutsch” in Launchpad or in the “Applications” folder of your home folder – feel free to drag it to the Dock.

  2. Start

Already have an older version? How to update

The latest version is always on the download page: lukasdiegans.github.io/me-goos-ta-deutsch/download – one package for Windows, macOS and Linux.

Your cards, pictures and PDFs are kept – the new version brings none of them, only its example cards.

  1. Quit the running interface (⏻ at the top right).
  2. Unblock the new ZIP file (Windows: step 1) and extract it into a new folder – “Extract All …” suggests one by itself, and the Mac always creates a new one.
  3. Double-click the start file in the new folder. It finds the previous folder and asks whether your cards should be taken over: “Yes”, or in the start window simply Enter. Cards, pictures, already enhanced images, settings and your own goose image are copied – nothing needs to be downloaded again.
  4. From now on the icon starts the new version. The old folder stays unchanged and can go once everything is fine.

Also possible: extract over the old folder and choose “Replace the files in the destination” – only program files are replaced, never your cards or pictures.

What happens on the first start

  • Its own Python – official from python.org (Windows) or python-build-standalone (Mac and Linux), checksum verified. It lives in your user folder, needs no administrator rights and leaves other Python installations alone.
    Windows: %LOCALAPPDATA%\Me-Goos-ta-Deutsch · Mac: ~/Library/Application Support/Me-Goos-ta-Deutsch · Linux: ~/.local/share/me-goos-ta-deutsch
  • Packages Pillow, NumPy, ReportLab, pypdfium2 (from pypi.org). Bigger extras – the tools image enhancement (Real-ESRGAN), automatic translation, AI images and more languages for the back – aren’t preinstalled: you choose them when you first open the program or later under “Tools”. With the “Learn cards” tool you practise your cards right in the program, like in Anki (tab “🎓 Learn”).
  • Icon on the desktop and in the Start menu (Windows), an app in “Applications” (Mac) or an entry in the application menu (Linux).
  • The download mark is removed from the program's own files so later starts are not blocked again.

On every later start the start program checks within seconds that everything is there. If the interface is already running, it just opens the browser. If something is missing or damaged, it repairs it by itself.

Where is what?

Programm/ holds the program and your work: bilder/ (your photos), karten.csv (the words), ausgabe/ (the finished PDFs). In the interface, “Tools” opens all folders directly. How to make cards: interface → “Help” or Programm/LEITFADEN_en.md.

Uninstall

The easiest way is the last tab “Uninstall” in the interface – there you can also save all cards and ideas to a file first. By hand:

Windows: delete the desktop icon · delete the folder %LOCALAPPDATA%\Me-Goos-ta-Deutsch (Windows key + R, type %LOCALAPPDATA%, Enter) · delete the program folder (careful: it holds your pictures and PDFs).
Mac: delete “Me Goos-ta Deutsch” from “Applications” · in Finder “Go → Go to Folder …”: delete ~/Library/Application Support/Me-Goos-ta-Deutsch · delete the program folder.
Linux: delete ~/.local/share/applications/me-goos-ta-deutsch.desktop and ~/.local/share/me-goos-ta-deutsch · delete the program folder.

Privacy: everything stays on your computer. The internet is only used for the setup (python.org, pypi.org, github.com), for tools you install yourself (models and fonts from github.com or huggingface.co, checked by checksum) and – only if you switch on automatic translation – for translation suggestions (Wiktionary, MyMemory or DeepL); then only the word to be translated is sent. The program only checks for new versions when you click “Check for a new version”: one request to api.github.com, with no data about you or your cards. The interface can only be reached from this computer unless you switch on phone access (Wi-Fi, with PIN).

Tus cartas, imágenes y PDF se conservan: la versión nueva no trae nada de eso, solo sus cartas de ejemplo.

  1. Cierra la interfaz que esté abierta (⏻ arriba a la derecha).
  2. Desbloquea el ZIP nuevo (Windows: paso 1) y descomprímelo en una carpeta nueva; «Extraer todo …» propone una sola, y la Mac siempre crea una nueva.
  3. Haz doble clic en el archivo de inicio de la carpeta nueva. Encuentra la carpeta anterior y pregunta si quieres pasar tus cartas: «Sí», o en la ventana de inicio simplemente Intro. Se copian cartas, imágenes, imágenes ya mejoradas, ajustes y tu imagen de ganso; no hay que descargar nada de nuevo.
  4. Desde ahora el icono abre la versión nueva. La carpeta anterior queda sin cambios y puedes borrarla cuando todo esté bien.

También se puede: descomprimir sobre la carpeta anterior y elegir «Reemplazar los archivos en el destino»; solo se reemplazan archivos del programa, nunca tus cartas ni tus imágenes.

Qué pasa en el primer inicio

  • Python propio: oficial de python.org (Windows) o python-build-standalone (Mac y Linux), con suma de verificación. Se guarda en tu carpeta de usuario, no necesita permisos de administrador y no toca otras instalaciones de Python.
    Windows: %LOCALAPPDATA%\Me-Goos-ta-Deutsch · Mac: ~/Library/Application Support/Me-Goos-ta-Deutsch · Linux: ~/.local/share/me-goos-ta-deutsch
  • Paquetes Pillow, NumPy, ReportLab, pypdfium2 (de pypi.org). Los extras más grandes, las herramientas mejora de imagen (Real-ESRGAN), traducción automática, imágenes IA y más idiomas para el reverso, no vienen preinstalados: los eliges al abrir el programa por primera vez o después en «Herramientas». Con la herramienta «Aprender cartas» practicas tus cartas dentro del programa, como en Anki (pestaña «🎓 Aprender»).
  • Icono en el escritorio y en el menú Inicio (Windows), una app en «Aplicaciones» (Mac) o una entrada en el menú de aplicaciones (Linux).
  • Se quita la marca de descarga de los archivos del programa para que los siguientes inicios no se bloqueen.

En cada inicio posterior, el programa de inicio revisa en segundos que todo esté. Si la interfaz ya está abierta, solo abre el navegador. Si falta algo o algo está dañado, lo repara solo.

¿Dónde está cada cosa?

Programm/ contiene el programa y tu trabajo: bilder/ (tus fotos), karten.csv (las palabras), ausgabe/ (los PDF terminados). En la interfaz, «Herramientas» abre todas las carpetas. Cómo hacer tarjetas: interfaz → «Ayuda» o Programm/LEITFADEN_es.md.

Problemas y soluciones

¿Qué pasa?¿Qué hacer?
«Control inteligente de aplicaciones … bloqueó»Paso 1 («Desbloquear») en el ZIP antes de descomprimir, o directamente en el archivo de inicio: clic derecho → Propiedades → Desbloquear → Aceptar.
«Windows protegió su PC»«Más información» → «Ejecutar de todas formas».
Ventana: «Primero descomprime el archivo ZIP»El archivo de inicio se abrió dentro del ZIP. Primero descomprime (paso 2) y luego inicia en la carpeta nueva.
«No hay conexión a internet»Solo el primer inicio necesita internet (unos 90 MB). Revisa el wifi e inicia de nuevo; lo ya descargado se reutiliza.
«Windows bloquea un archivo de la biblioteca de imágenes»El Control inteligente de aplicaciones no permite las bibliotecas de imágenes (no firmadas por Microsoft). El programa de inicio prueba solo versiones anteriores y muy usadas. Si no ayuda, la ventana muestra las opciones.
El antivirus avisa algoCasi siempre es una falsa alarma con archivos recién descargados: permítelo en «Seguridad de Windows → Historial de protección» e inicia de nuevo.
Al hacer clic en el icono no pasa nadaHaz doble clic una vez en el archivo de inicio de la carpeta del programa: revisa y repara todo. Los detalles están en protokoll.txt, en la carpeta de datos (ver arriba).
No se abre el navegadorLa dirección aparece en la ventana de inicio (http://127.0.0.1:…): cópiala en el navegador.
Carpeta movida o versión nueva descomprimidaHaz doble clic una vez en el archivo de inicio de la carpeta nueva. Ofrece pasar tus cartas de la carpeta anterior; Python y los paquetes se reutilizan y después el icono apunta a la carpeta nueva.
Mac: «no se puede abrir» / «sin permiso»Mira el paso 2 de Mac: el método de Terminal (sh + arrastrar el archivo) siempre funciona.

Desinstalar

Lo más fácil es la última pestaña «Desinstalar» de la interfaz; ahí también puedes guardar antes todas las cartas e ideas en un archivo. A mano:

Windows: borra el icono del escritorio · borra la carpeta %LOCALAPPDATA%\Me-Goos-ta-Deutsch (tecla Windows + R, escribe %LOCALAPPDATA%, Intro) · borra la carpeta del programa (cuidado: contiene tus imágenes y PDF).
Mac: borra «Me Goos-ta Deutsch» de «Aplicaciones» · en Finder «Ir → Ir a la carpeta …»: borra ~/Library/Application Support/Me-Goos-ta-Deutsch · borra la carpeta del programa.
Linux: borra ~/.local/share/applications/me-goos-ta-deutsch.desktop y ~/.local/share/me-goos-ta-deutsch · borra la carpeta del programa.

Privacidad: todo se queda en tu computadora. Internet solo se usa para la instalación (python.org, pypi.org, github.com), para las herramientas que tú instales (modelos y fuentes de github.com o huggingface.co, con suma de verificación) y, solo si activas la traducción automática, para sugerencias de traducción (Wiktionary, MyMemory o DeepL); en ese caso solo se envía la palabra a traducir. El programa solo busca versiones nuevas cuando haces clic en «Buscar una versión nueva»: una consulta a api.github.com, sin datos sobre ti ni tus cartas. La interfaz solo es accesible desde esta computadora, salvo que actives el acceso desde el celular (wifi, con PIN).
